# Reify

Reify exposes website capabilities as typed tools for AI agents.

## Language

**Pre-warmed wire profile**:
A curated collection of typed API request plans for a recognized web service.
It describes available operations without containing a user's credentials or results.
_Avoid_: Captured session, authenticated profile

**Live discovery**:
Observation of a target's current responses and browser traffic to discover its API operations.
_Avoid_: Profile lookup
